# AstroSky PWA 0.9.0

설치 링크: https://astrosky.jmgj-kakao-search.workers.dev/

아이폰·아이패드의 Safari에서 링크를 열고 공유 메뉴의 **홈 화면에 추가**를 선택한다. 홈 화면의 AstroSky 아이콘을 실행한 뒤 장비·장소·개인 기상 키를 설정하고 **설정 → 업데이트 확인 → 오프라인 사용 준비**를 완료한다. Safari 탭과 홈 화면 앱의 저장소는 분리될 수 있으므로 홈 화면 앱에서 준비한다.

전체 사용법·공유 코드·배포 구조는 [PWA README](../pwa/README.md)에 기록한다. 기본 오프라인 자산은 약 121MB이며 선택한 지역·사진·사용자 배경은 추가된다. PWA ZIP은 정적 자산·Worker 코드의 보관용 파일이며 로컬에서 더블 클릭하는 설치 파일이 아니다.

## 공유 기능과 저장

Android의 MobileApp·SkyViewer·기상·시상·좌표·사진·장비·필터·화각·촬영 안내·사용자 배경·북쪽 정렬을 공유한다. Python 계산 작업과 원본 자료 해상도도 유지한다. 플랫폼별 센서·파일·개인 키·업데이트 연결은 브라우저 방식으로 바꾼다.

개인 키는 암호화 IndexedDB, 지역 자료는 버전과 독립된 CacheStorage에 저장한다. 야간광 파일은 고정 목록의 크기·SHA-256을 검증한다. 업데이트는 새 앱 자산을 준비한 뒤 구 앱 자산만 정리하며 키·기상·지역·장비·사용자 배경은 유지한다. 사용자 배경의 전용 Service Worker가 PWA의 루트 Worker를 교체하지 않도록 했다. 오프라인 페이지 응답은 HTTP 리디렉션·전송 압축 메타데이터를 정규화해 저장한다.

공개 서버에서 제주과학고등학교 검색이 실제 Kakao 결과를 반환함을 확인했다. 기존 Kakao·Black Marble Worker는 서비스 바인딩으로 연결하며 운영자 키를 PWA에 복사하지 않는다. Meteoblue 키는 수동 요청의 POST 본문을 통해 연결하고 서버 저장·캐시·로그에 보관하지 않는다.

## 검증과 한계

Chromium의 독립 프로필에서 키·장소·사용량·기상 캐시 재실행 복원, 복원 시 새 조회 없음, 방향 입력·북쪽 정렬과 기본 자산 211개의 오프라인 준비를 확인했다. 실제 제주 지역 DEM·Black Marble과 시험 기상·달 위치 입력을 사용한 WASM 모델은 온라인과 네트워크 차단 후 재실행에서 모두 `black-marble-dem`, 준비된 자료, 야간광 963개 픽셀과 SQM 17.698을 반환했다. 시험 입력의 실행 일치 확인이며 실제 관측 밝기나 모델 정확도 검증은 아니다.

Windows WebKit 시험 브라우저에서 천체 렌더링, Service Worker 활성화, 오프라인 자산 준비와 키·장소의 페이지 재실행 복원을 확인했다. 영구 프로필·네트워크 차단 후 탐색 자동화는 내부 오류나 Web Inspector 차단이 있어 Apple 실기기 검증으로 간주하지 않는다. 실제 iPhone/iPad의 홈 화면 앱 재실행, 센서 권한·자기장 간섭·하늘 방향·북쪽 정렬 및 성능은 별도로 확인해야 한다.

프론트엔드 116개, PWA 방향·저장 10개, PWA 서버 6개, Windows·Android Node 31개, Android Java 10개 테스트를 통과했다. PWA·Android 타입 검사와 배포 빌드를 수행했다. 개인 기상 요청 검증에는 시험 키·응답만 사용했으며 실제 계정 크레딧을 소비하지 않았다.
