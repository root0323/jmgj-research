# AstroSky PWA

## 0.9.2 · 별궤적

공통 하늘 화면의 **별자리선 → 별궤적**으로 선택한 천체의 같은 시각, 1년간 위치를 점선으로 본다. 북극성은 확대하고, 태양은 한낮 시각을 설정한 뒤 축소해 아날렘마를 볼 수 있다. 현재 위치는 작은 원과 `현재`로 표시하며, 선택 해제·기능 끄기 때 숨긴다. 계산 방법과 검증은 [Windows 기록](WINDOWS_APP.md)의 0.9.2 항목과 같다. 추가 API 키·기상 요청·유료 조회는 필요하지 않다.

0.9.2의 기본 오프라인 자산은 211개, 121,118,060 bytes다. 업데이트는 기존 Service Worker 경로를 사용하며 개인 키·장소·장비·지역·기상·배경 저장 방식을 변경하지 않는다. 공통 124개, PWA 14개와 서버 6개 테스트 및 production 빌드·타입 검사를 통과했다. Apple 실기기의 센서 정확도를 새로 검증한 것은 아니다. 배포 ZIP 222개 항목의 압축 해제 바이트 일치를 확인했으며 59,647,445 bytes, SHA-256 `49ca633726e3d66df03c15edbb54055637cedaf6653a87a424ae4a0d009be178`다. ZIP 게시와 공개 웹서비스 배포는 구분한다.

2026-10-19 사용자 승인 후 기존 공개 웹앱에 0.9.2를 배포했다. Cloudflare Worker 버전 ID는 `93ed2c54-bcda-48cc-a56d-dfd86888dc25`다. 공개 `offline-assets.json`의 버전 0.9.2와 211개 파일을 확인하고, manifest·index.html·sw.js의 SHA-256이 로컬 최종 빌드와 같음을 대조했다. 공개 웹앱의 실제 엔진에서 **별자리선 → 별궤적** 메뉴와 태양의 점선 궤적·현재 위치 표시를 확인했으며 브라우저 오류 로그는 없었다. Apple 실기기 시험 결과로 간주하지 않는다. [정식 릴리스의 PWA ZIP](https://github.com/root0323/jmgj-research/releases/download/v0.9.2/AstroSky-0.9.2-PWA.zip)도 공개 크기·SHA-256이 위 검증본과 일치한다.

설치 링크: https://astrosky.jmgj-kakao-search.workers.dev/

아이폰·아이패드의 Safari에서 링크를 열고 공유 메뉴의 **홈 화면에 추가**를 선택한다. 홈 화면의 AstroSky 아이콘을 실행한 뒤 장비·장소·개인 기상 키를 설정하고 **설정 → 업데이트 확인 → 오프라인 사용 준비**를 완료한다. Safari 탭과 홈 화면 앱의 저장소는 분리될 수 있으므로 홈 화면 앱에서 준비한다.

전체 사용법·공유 코드·배포 구조는 [PWA README](../pwa/README.md)에 기록한다. 기본 오프라인 자산은 약 121MB이며 선택한 지역·사진·사용자 배경은 추가된다. PWA ZIP은 정적 자산·Worker 코드의 보관용 파일이며 로컬에서 더블 클릭하는 설치 파일이 아니다.

## 공유 기능과 저장

Android의 MobileApp·SkyViewer·기상·시상·좌표·사진·장비·필터·화각·촬영 안내·사용자 배경·북쪽 정렬을 공유한다. Python 계산 작업과 원본 자료 해상도도 유지한다. 플랫폼별 센서·파일·개인 키·업데이트 연결은 브라우저 방식으로 바꾼다.

개인 키는 암호화 IndexedDB, 지역 자료는 버전과 독립된 CacheStorage에 저장한다. 야간광 파일은 고정 목록의 크기·SHA-256을 검증한다. 업데이트는 새 앱 자산을 준비한 뒤 구 앱 자산만 정리하며 키·기상·지역·장비·사용자 배경은 유지한다. 사용자 배경의 전용 Service Worker가 PWA의 루트 Worker를 교체하지 않도록 했다. 오프라인 페이지 응답은 HTTP 리디렉션·전송 압축 메타데이터를 정규화해 저장한다.

공개 서버에서 제주과학고등학교 검색이 실제 Kakao 결과를 반환함을 확인했다. 기존 Kakao·Black Marble Worker는 서비스 바인딩으로 연결하며 운영자 키를 PWA에 복사하지 않는다. Meteoblue 키는 수동 요청의 POST 본문을 통해 연결하고 서버 저장·캐시·로그에 보관하지 않는다.

## 검증과 한계

### 0.9.1 부수 기능 통일

최대 FOV 150도는 공유 SkyViewer와 모바일 렌더러 양쪽에서 제한합니다. PWA의 화면 안전 영역을 추가해 노치·홈 표시줄과 버튼·정보 창이 겹치지 않도록 하고, 모바일 패널 높이·폭을 안전 영역 기준으로 계산합니다. 하늘의 핀치 확대는 화면 확대와 분리하고, Safari 입력창 자동 확대를 피하는 글자 크기를 적용합니다. 북쪽 기준 센서 권한 요청을 추가했으며, 오프라인 재실행에서는 이미 설치된 Worker를 먼저 사용합니다. Worker 응답에 제한 시간을 두어 화면이 계속 비어 있는 상태를 방지합니다.

정렬·평활화·손 조작 시 따라가기 해제, 선택된 천체에서 화면 이동, 개인 키·장소·장비·필터·기상 저장, 좌표계·화각·촬영 안내·출처·API 도움말·앱 업데이트는 Android와 같은 구성요소를 사용합니다. Apple 기기의 실제 센서 정확도는 별도의 실기기 검증이 필요합니다.

Chromium의 실제 엔진에서 매 프레임 270도 초과 확대 입력을 시험했으며 화면 렌더 직전 최대값은 150도, 정상 확대는 6도로 확인했습니다. iPhone 세로 393×852·가로 852×393·iPad 1024×1366에서 안전 영역을 모의해 WebKit과 Chromium의 하늘·패널·도구·API 안내 창이 영역 안에 배치되는 것을 확인했습니다. Chromium의 기본 자산 211개 오프라인 준비와 브라우저 완전 재실행에서 키·장소·크레딧이 복원됐고 새 기상 요청은 없었습니다. 모의 안전 영역 검증은 Apple 실기기 센서·운영체제 검증을 대신하지 않습니다. PWA 방향·저장·재실행 테스트 14개와 서버 6개를 통과했습니다.

Chromium의 독립 프로필에서 키·장소·사용량·기상 캐시 재실행 복원, 복원 시 새 조회 없음, 방향 입력·북쪽 정렬과 기본 자산 211개의 오프라인 준비를 확인했다. 실제 제주 지역 DEM·Black Marble과 시험 기상·달 위치 입력을 사용한 WASM 모델은 온라인과 네트워크 차단 후 재실행에서 모두 `black-marble-dem`, 준비된 자료, 야간광 963개 픽셀과 SQM 17.698을 반환했다. 시험 입력의 실행 일치 확인이며 실제 관측 밝기나 모델 정확도 검증은 아니다.

Windows WebKit 시험 브라우저에서 천체 렌더링, Service Worker 활성화, 오프라인 자산 준비와 키·장소의 페이지 재실행 복원을 확인했다. 영구 프로필·네트워크 차단 후 탐색 자동화는 내부 오류나 Web Inspector 차단이 있어 Apple 실기기 검증으로 간주하지 않는다. 실제 iPhone/iPad의 홈 화면 앱 재실행, 센서 권한·자기장 간섭·하늘 방향·북쪽 정렬 및 성능은 별도로 확인해야 한다.

프론트엔드 116개, PWA 방향·저장 10개, PWA 서버 6개, Windows·Android Node 31개, Android Java 10개 테스트를 통과했다. PWA·Android 타입 검사와 배포 빌드를 수행했다. 개인 기상 요청 검증에는 시험 키·응답만 사용했으며 실제 계정 크레딧을 소비하지 않았다.
