# 개인 연구 앱 — 추후 추가 기능

2026-10-06 사용자 요청으로 기록한 개발 목록이다.

## 구현 완료 (2026-10-08)

- 실행 안정화·표시 최적화: 0.4.2에서 서버 준비 전에 안내 창을 표시하고 화면·계산 서버와 브라우저 세션을 동시에 준비한다. 작은 인증 준비 응답·느린 첫 실행 대기·준비 중 취소·해당 실행의 서버 종료 처리를 개선했다. 계산 라이브러리는 필요한 시점에 불러오며 별 목록의 반복 스캔을 줄였다. 웹 66개·백엔드 61개·앱 14개 테스트, Windows 연속 시작·종료 진단과 저장 예보 18개 계산 결과 일치를 확인했다. 기존 모델 계수·자료 해상도는 유지하며 실제 성능 측정과 릴리스는 `WINDOWS_APP.md` 참고.

- 카메라 설정 입력: 설정 창의 카메라 탭에서 센서 가로·세로 크기(mm)와 픽셀 크기(μm)만 입력한다. 양수·소수 입력을 지원하고 세 값을 저장하면 앱을 다시 켜도 불러온다. 제품명 검색·제품별 사양 목록·촬영 화각 계산은 이번 입력 기능에 포함하지 않는다.
- 필터 설정 선택: RGB의 R·G·B와 SHO의 SⅡ·Hα·OⅢ, 총 6개 중 현재 사용하는 필터 하나를 선택·저장한다. 다른 그룹의 필터를 고르면 이전 선택은 해제되며 선택 해제·저장과 재실행 시 복원을 지원한다. 필터 투과율·대역폭에 따른 계산 모델 변경은 별도 후속 작업이다.

- 카카오 공용 검색: 무료 Cloudflare Worker에 운영자 키를 비밀 변수로 등록하고 0.4.0 앱에 공개 주소만 포함한다. 사용자별 카카오 계정·키 없이 국내 장소·자동완성·주소·역지오코딩을 사용한다. 키 없는 백엔드에서 제주과학고 검색과 해외 Mauna Kea의 기존 공개 검색 경로를 확인했다. 무료 한도는 전체 사용자가 공유한다.

- Windows 앱 기반: Electron 창에 기존 관측 웹과 Next.js·Python 계산 서버를 함께 묶었다. 앱별 고정 주소·브라우저 프로필로 기상 캐시와 설정을 유지하고 기존 DEM·Black Marble 폴더를 연결한다. 메뉴에서 데이터 폴더를 열거나 기존 자료 폴더를 지정한다. 0.2.0부터 검증한 2025년 전 세계 Black Marble 압축본 540개(약 1.14GB)를 설치 파일에 포함하고 DEM은 장소 선택 시 주변 약 30km를 자동 저장·재사용한다. 사용자 NASA·AWS 계정은 필요 없다. API 키·연구 원자료는 포함하지 않는다. Windows x64 설치 빌드와 후속 배포 작업은 `WINDOWS_APP.md` 참고. 캐시 용량·삭제 관리와 기준 연도 갱신은 후속 기능이다.

- 딥스카이 사진·유명 이름 검색: 자동완성 목록을 눌러 이동할 때도 DSS 사진을 켜고 확대하도록 수정했다. 안드로메다 은하·오리온 성운·말머리 성운 등 대표 이름 21개와 별칭을 카탈로그 번호에 연결하고 부분 이름 자동완성을 지원한다. 말머리 성운 검색은 IC 434의 주변 사진 영역으로 이동한다. 사진을 받으려면 인터넷이 필요하다.

- 앱 내부 업데이트: Windows 0.3.0부터 설치한 앱에서 공개 GitHub Releases의 새 정식 버전을 자동·수동 확인한다. 다운로드 진행률과 재시작/나중에 선택을 제공하고 설정·기상 캐시·DEM을 유지한다. NSIS 차등 다운로드와 SHA-512 검증을 사용하며 일반 앱 종료로 임의 설치하지 않는다. 0.2.0 사용자는 한 번 새로 설치해야 한다. 2026-10-08 0.4.1 정식 릴리스와 0.4.0 비교 blockmap을 공개하고 기존 0.4.0 앱에서 조회·다운로드·파일 검증·기존 설치 업그레이드를 확인했다. 고정 주소·브라우저 프로필·DEM 자료가 유지됐으며 비교 계획상 설치 파일 약 1.29GB 중 바뀐 부분 약 1.2MB만 필요했다. 전송량에는 비교 자료가 추가되며 캐시나 네트워크 조건에 따라 전체 다운로드로 대체될 수 있다. 절차는 `WINDOWS_APP.md` 참고.

- 전 세계 DEM 다운로드·무손실 압축: 3006 로컬 화면에서 공개 Copernicus GLO-90 고도 타일 26,475개(다운로드 원본 약 71.06GB)를 계정 없이 받는다. 원본 격자·모든 고도 비트·마스크·좌표·속성을 비교한 ZSTD 압축본으로 교체해 디스크 사용량을 줄인다. 기존 원본부터 재다운로드 없이 변환하며 실패 복구·해시 검증·중단·이어받기와 로컬 지형 연결을 지원한다. 전체 26,475개 다운로드·검증이 완료됐으며 실제 저장 용량은 49.61GB, 절약 용량은 21.45GB다.

- Black Marble 용량 축소 시험: NOAA-20 VJ146A4 V2 연별 타일에서 현재 모델이 읽는 밝기·품질·좌표만 원본 해상도로 보존하고 무손실 압축하는 도구를 추가했다. 전체 값·자료형·속성을 비교한 뒤 저장하며 기존 파일은 덮어쓰지 않는다. 2025년 서울·제주 타일 실파일은 약 103MB에서 3.55MB로 축소됐다. 2025년 전 세계 540개 타일 처리 완료 후 앱용 압축본은 합계 약 1.14GB이며 Windows 0.2.0 설치 자료에 포함한다. `DATA_CONNECTIONS.md` 참고.
- 전 세계 연별 Black Marble 준비 도구: 3005 로컬 화면에서 NASA 토큰을 직접 입력해 2025년 540개 타일을 순차 다운로드·압축·전체 값 검증할 수 있다. OneDrive 밖에 원본·압축 자료를 함께 보관하고 중단·완료 파일 이어받기·공간 확인을 지원한다. 이미 받은 타일은 가져와 재사용하며, 백엔드는 검증된 연별 타일을 장소별 DEM과 연결한다. 전체 540개 인증 다운로드·압축·유지 값 검증을 완료했다. 원본 51.14GB는 별도로 보관한다.

- 지역별 계산 연결 검증: 서울·제주·설악산·산티아고·마우나케아·트롬쇠의 실자료를 연결했다. 지역 DEM 경계 반올림으로 생기던 결측 한 줄을 수정했고, 시험 입력 36개 조건의 성분 합·달빛·구름·AOD 연결을 검증했다. 실제 예보 18개 시점도 조회해 15개 전체 모델·3개 운저 부족 간이 추정을 확인했다. 구름 0%에는 운저가 없어도 계산하도록 보정했으며 저장 기상만 재검증하는 기능·재현 JSON을 추가했다. 추가 기상 차감 없이 같은 결과가 재현됐다. 과학적 정확도 검증과 구분하며 자세한 결과·후속 문제는 `MODEL_VALIDATION.md`에 기록했다.

- 외부 자료 연결 구조: 카카오·VWorld 키 입력용 로컬 설정 화면, Copernicus GLO-90 지형과 NASA Black Marble의 장소별 다운로드·로컬 캐시, 무료 기상 자료와 Stellarium 달 위치를 연구 모델에 전달하는 경로를 추가했다. 계정 키·NASA 토큰의 발급과 실제 인증 조회는 별도 필요하다. 자세한 준비 절차와 자료 차이는 `DATA_CONNECTIONS.md`에 기록했다.

- 은하수: Stellarium 엔진의 기본 은하수 모듈에 공식 예제 HiPS 이미지를 연결한다. 자료는 앱에 포함하고 기본 표시하며, 천체 검색에서 `은하수`, `Milky Way`, `MilkyWay`로 찾아 선택하면 현재 장소·시간에 은하면이 가장 높이 보이는 방향으로 이동해 90° 시야로 표시한다. 별도의 켜기·끄기 버튼은 두지 않는다. 출처 탭에 자료 링크를 추가했다.
- 은하수 검색 선택 경계선: 표시 중인 은하수 이미지에서 추출한 두 가장자리 윤곽을 함께 표시한다. 장소·시간과 시야 이동에 맞춰 천구 위에서 움직이며, 다른 천체를 선택하거나 선택을 해제하면 숨긴다. 추가 API 조회 없이 앱에 포함된 좌표를 사용한다.
- 적도좌표계 선: 하단 `좌표계` 메뉴에서 지평좌표·적도좌표를 개별 체크하여 표시한다. 두 좌표계를 동시에 표시할 수 있다.
- 적도, 황도: 하단 `별자리선` 메뉴에서 별자리선·적도·황도를 개별 체크하여 표시한다. 새 선은 기존 지평좌표선과 같은 엔진 렌더링과 색상을 사용한다.
- 설정 창 구조: 하단 설정 버튼으로 독립된 창을 열고, 망원경 설정 → 카메라 설정 → 필터 설정 → 배경 설정 → 딥스카이별 촬영 세팅 정보 → 출처 순서로 탭을 전환한다. 망원경·카메라·필터의 입력·저장과 출처 목록을 제공하며 배경·딥스카이별 촬영 세팅 정보는 빈 내용 영역만 준비했다. ×·Esc로 닫을 수 있다.
- 출처 탭: 사용자 GitHub 계정·연구 저장소·원본 코드와 기상·시상 API, 장소·지도 제공자, Stellarium·DSS·HYG·OpenNGC 자료의 공식 링크와 용도를 표시한다. 이후 외부 자료를 추가할 때 출처 목록도 함께 갱신한다.
