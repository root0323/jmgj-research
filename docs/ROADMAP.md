# 개인 연구 앱 — 추후 추가 기능

2026-10-06 사용자 요청으로 기록한 개발 목록이다.

## 구현 완료 (2026-10-07)

- 전 세계 DEM 다운로드: 3006 로컬 화면에서 공개 Copernicus GLO-90 고도 타일 26,475개(원본 약 71.06GB)를 계정 없이 저장한다. 원본 GeoTIFF·격자·높이 값을 유지하며 ETag·전체 배열 검증, 중단·이어받기·저장 공간 확인과 로컬 지형 연결을 지원한다. 실제 다운로드는 진행 중이며 전체 완료 상태는 진행 화면에서 확인한다.

- Black Marble 용량 축소 시험: NOAA-20 VJ146A4 V2 연별 타일에서 현재 모델이 읽는 밝기·품질·좌표만 원본 해상도로 보존하고 무손실 압축하는 도구를 추가했다. 전체 값·자료형·속성을 비교한 뒤 저장하며 기존 파일은 덮어쓰지 않는다. 2025년 서울·제주 타일 실파일은 약 103MB에서 3.55MB로 축소됐다. 전 세계 실제 압축 용량은 미측정이며, 최종 사용자용 지역 패키지 배포와 Windows 앱 저장 관리는 남아 있다. `DATA_CONNECTIONS.md` 참고.
- 전 세계 연별 Black Marble 준비 도구: 3005 로컬 화면에서 NASA 토큰을 직접 입력해 2025년 540개 타일을 순차 다운로드·압축·전체 값 검증할 수 있다. OneDrive 밖에 원본·압축 자료를 함께 보관하고 중단·완료 파일 이어받기·공간 확인을 지원한다. 이미 받은 타일은 가져와 재사용하며, 백엔드는 검증된 연별 타일을 장소별 DEM과 연결한다. 다운로드 도구 검증과 기존 샘플 가져오기를 마쳤으며, 나머지 실제 인증 다운로드는 사용자 토큰 입력 후 진행한다.

- 외부 자료 연결 구조: 카카오·VWorld 키 입력용 로컬 설정 화면, Copernicus GLO-90 지형과 NASA Black Marble의 장소별 다운로드·로컬 캐시, 무료 기상 자료와 Stellarium 달 위치를 연구 모델에 전달하는 경로를 추가했다. 계정 키·NASA 토큰의 발급과 실제 인증 조회는 별도 필요하다. 자세한 준비 절차와 자료 차이는 `DATA_CONNECTIONS.md`에 기록했다.

- 은하수: Stellarium 엔진의 기본 은하수 모듈에 공식 예제 HiPS 이미지를 연결한다. 자료는 앱에 포함하고 기본 표시하며, 천체 검색에서 `은하수`, `Milky Way`, `MilkyWay`로 찾아 선택하면 현재 장소·시간에 은하면이 가장 높이 보이는 방향으로 이동해 90° 시야로 표시한다. 별도의 켜기·끄기 버튼은 두지 않는다. 출처 탭에 자료 링크를 추가했다.
- 은하수 검색 선택 경계선: 표시 중인 은하수 이미지에서 추출한 두 가장자리 윤곽을 함께 표시한다. 장소·시간과 시야 이동에 맞춰 천구 위에서 움직이며, 다른 천체를 선택하거나 선택을 해제하면 숨긴다. 추가 API 조회 없이 앱에 포함된 좌표를 사용한다.
- 적도좌표계 선: 하단 `좌표계` 메뉴에서 지평좌표·적도좌표를 개별 체크하여 표시한다. 두 좌표계를 동시에 표시할 수 있다.
- 적도, 황도: 하단 `별자리선` 메뉴에서 별자리선·적도·황도를 개별 체크하여 표시한다. 새 선은 기존 지평좌표선과 같은 엔진 렌더링과 색상을 사용한다.
- 설정 창 구조: 하단 설정 버튼으로 독립된 창을 열고, 망원경 설정 → 카메라 설정 → 필터 설정 → 배경 설정 → 딥스카이별 촬영 세팅 정보 → 출처 순서로 탭을 전환한다. 기존 초점거리·구경 입력과 저장 기능은 망원경 설정으로 옮겼으며, 나머지 탭은 제목과 빈 내용 영역만 준비했다. ×·Esc로 닫을 수 있다.
- 출처 탭: 사용자 GitHub 계정·연구 저장소·원본 코드와 기상·시상 API, 장소·지도 제공자, Stellarium·DSS·HYG·OpenNGC 자료의 공식 링크와 용도를 표시한다. 이후 외부 자료를 추가할 때 출처 목록도 함께 갱신한다.
