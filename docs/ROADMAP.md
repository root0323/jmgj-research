# 개인 연구 앱 — 추후 추가 기능

2026-10-06 사용자 요청으로 기록한 개발 목록이다.

## 구현 완료 (2026-10-07)

- 적도좌표계 선: 하단 `좌표계` 메뉴에서 지평좌표·적도좌표를 개별 체크하여 표시한다. 두 좌표계를 동시에 표시할 수 있다.
- 적도, 황도: 하단 `별자리선` 메뉴에서 별자리선·적도·황도를 개별 체크하여 표시한다. 새 선은 기존 지평좌표선과 같은 엔진 렌더링과 색상을 사용한다.

## 추후 추가

- 은하수
- 기본배경
- 장비 저장 탭
- 배경 추가 탭
- 딥스카이별 촬영세팅
- 출처 탭: 제공기관과 자료 출처를 한곳에서 확인한다. 기능 화면의 시상 값에는 범위만 표시하고 출처 문구를 붙이지 않는다.

SQM 관측값은 모델 개선·검증을 위한 연구 데이터이며 앱 기능으로 추가하지 않는다.
