# 지역별 모델 연결 검증

2026-10-08 현재, 전 세계 자료 저장 완료 후 연구 모델에 실제로 연결되는지 확인했다. **현장 실측 정확도 검증과 구분한다.**

## 완료한 저장 자료

- Copernicus GLO-90: 26,475개 고도 타일. 원본 합계 71,064,817,393 bytes → 실제 저장 49,612,154,998 bytes. 21,452,662,395 bytes 절약. 원본 격자·고도 비트·마스크·좌표를 보존했다.
- Black Marble: 2025년 NOAA-20 VJ146A4 V2 540개 타일. 원본 합계 51,139,704,099 bytes, 앱용 압축본 합계 1,137,270,637 bytes. 원본은 별도로 남아 있으므로 현재 연구 컴퓨터의 전체 점유량은 압축본 용량보다 크다.
- 이 자료들은 연구 컴퓨터의 로컬 저장소에 있다. GitHub나 최종 사용자용 앱에 전체 자료를 포함한 것은 아니다.

## 발견·수정한 연결 오류

지역 DEM을 임의의 소수 좌표 경계로 합치면 Rasterio의 창 크기 반올림 때문에 끝에 결측 한 줄이 생겼다. 필요한 원본 타일이 모두 있어도 설악산·산티아고·마우나케아·트롬쇠에서 전체 모델 대신 간이 추정을 사용했다.

지역 경계를 Copernicus의 픽셀 중심 격자에 맞춰 바깥쪽으로 확장하고 바다용 0m 격자도 같은 기준에 맞췄다. 변경된 격자는 별도 캐시 이름으로 생성한다. 원본·압축 고도 파일은 수정하지 않는다. 실제 결측이나 미다운로드 육지 타일은 계속 거부한다. 고위도 원본의 넓은 경도 간격은 보관 파일에서 그대로 유지하며, 계산용 지역 모자이크는 기존처럼 최근접 표본의 1/1200도 작업 격자를 사용한다.

각 지역에서 맑음·운량 20%·운량 80%·AOD 증가·보름달의 지평선 위/아래를 비교했다. 총 36개 조건에서 성분의 유한성·비음수, 성분 합과 전체 복사휘도의 일치, 성분 계산과 실제 앱 계산의 일치를 확인했다. 지평선 아래 달빛과 맑은 하늘의 구름 반사광은 0이며, 달이 지평선 위에 있을 때 달빛과 흐린 하늘의 구름 반사광은 양수였다. AOD 변화도 결과에 반영됐다. 검증 프로세스에서는 외부 GET 요청을 차단했다.

재현 명령(자료 경로는 로컬 `.env` 설정):

```powershell
$env:PYTHONPATH = 'backend/src'
.venv/Scripts/python.exe -m app.scripts.validate_model_regions
```

전체 성분 결과는 Git에서 제외한 `.local-data/model-regions-controlled.json`에 저장된다. 새 회귀 테스트는 북/남반구 경계·고위도 경도 간격·실제 결측 거부를 포함한다. 백엔드 47개 테스트, 새 화면 lint와 TypeScript 검사를 통과했다.

## 실제 예보 검증 화면

개발 서버의 <http://127.0.0.1:3001/model-validation>에서 같은 여섯 장소를 선택할 수 있다. 로컬 개발 환경에서만 열리며 일반 배포에서는 404다.

1. Meteoblue 키를 화면에 직접 입력한다. 키는 화면 메모리에만 유지하고 서버 로그·기상 캐시·결과 JSON에 넣지 않는다.
2. 24시간 이내 같은 계정·좌표·무료 3시간 구성 캐시를 우선 사용한다. 새 조회가 필요하면 장소당 `airquality-3h`, `clouds-3h`, `air-3h`를 각각 한 번 요청한다. 여섯 장소 모두 새로 받으면 현재 단가 기준 약 144,000크레딧이며 응답 차감 헤더를 우선 기록한다. 기존 관측 화면과 같은 사용량 장부를 사용한다.
3. 지역 태양시 약 21시·0시·3시의 실제 Stellarium 달 위치·위상을 구하고, 저장 기상만 사용하는 앱의 계산 API로 전달한다. 명시적인 UTC 시각과 같은 +09:00 기상 파서를 사용하므로 해외 좌표도 서버 운영체제 시간대에 의존하지 않는다. 시간별 계산은 Meteoblue를 추가 조회하지 않는다.
4. 전체 모델/간이 추정, 필수 결측, AOD·구름·달 고도·픽셀 수를 표시한다. 패키지 조회 실패 시 나머지 장소는 요청하지 않는다. 결과 JSON은 사용자가 로컬에 저장할 수 있으며 개인 사용량이 포함되므로 Git에 올리지 않는다.

현재 실제 예보를 사용한 18개 시점 검증은 **키 재입력 후 실행이 필요하다.** 위의 오프라인 결과로 실제 예보 검증까지 완료했다고 판단하지 않는다.

## 후속 과학 검증

- 위도에 따라 Black Marble 픽셀의 실제 면적이 달라지는데 현재 모델은 연구 당시 고정 면적 `0.169 km²`를 사용한다. 전 세계의 절대 밝기 비교에는 면적 처리와 재보정이 필요하다.
- 밝은 픽셀 선별 상한 1,000개와 30km 반경이 결과에 미치는 영향을 확인해야 한다. 모든 지역에서 총 광량의 99%가 유지된다고 가정하면 안 된다.
- 약간 흐린 조건이 맑은 조건보다 어둡게 나오는 등 운량에 대한 단조성이 항상 성립하지 않는다. 현재 운저에 따른 산란 적분 범위와 구름 반사 항을 실측 데이터로 검토해야 한다. 이번 연결 수정에서 연구 계수를 다시 맞추지는 않았다.
- DSM에는 건물·식생이 포함된다. 관측자 높이, 근거리 능선 표본 간격, 지형 차폐와 지평선·박명 취급도 현장 자료와 비교한다.
- 날짜 변경선을 가로지르는 영역과 극지방은 현재 계산 경로의 지원 범위 밖이다. 여섯 지점의 통과를 모든 좌표의 정확도 보증으로 해석하지 않는다.
- SQM 관측값은 후속 모델 개선·검증 자료로 사용하며 사용자 기능으로 추가하지 않는다.
