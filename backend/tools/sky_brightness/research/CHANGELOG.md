# 모델 연구 변경 기록

## 2026-10-27 · 제주과학고 지도 핀과 유효 SQM-L 33개

- 최초 준비 요청보다 나중에 제공한 실제 관측표 21:08~21:13 KST와 지도 핀 33.426633°N, 126.530639°E를 우선했다. 원본 49칸·결측 16개·유효 33개를 보존하고 결측을 0이나 보간값으로 채우지 않았다.
- 운동장 중앙에서 먼저 받은 API는 `unused/`로 분리했다. 실제 핀 좌표에서 21:48 KST에 새로 받은 3시간 API 전체와 수신 기록, 지도 사진·좌표 변환 근거, 자료 해시를 저장했다. 오늘 조회 자료는 관측 후 수신한 모델 데이터다.
- 001 고정 검사: 기본 MSE/RMSE 1.86779255/1.36667207, 10월 22일 후보 1.88965523/1.37464731로 개선되지 않았다.
- 002는 기존과 같은 후보 계열·범위로 재보정했다. 선택된 기존 산란 후보의 보정 MSE/RMSE 1.25021433/1.11812983, 방향 검증 1.73683807/1.31789152였다. 경험적 구름·달빛 항의 방향 검증은 1.94124로 더 나빴다. 한 분할의 n=1과 탐색 상한을 명시했다.
- 태양 고도 약 −42.7°이므로 황혼 항을 적용하지 않았다. 달과 SQM-L 측정 방향의 각거리는 별도 진단으로 저장했으며 자동 제외하지 않았다. 역방향 날짜 검사와 시간 민감도·분할 ID·예측·각도별 그래프를 보존했다.
- 비교 그림이 결측 방향을 선으로 연결하지 않도록 수정하고, 일반 평가 보고서의 장소·태양 조건 설명을 데이터별로 읽도록 고쳤다. 관련 테스트 15개와 출처 목록 검사를 통과했다. 계산식·앱 기본값은 유지했다.

## 2026-10-26 · 탐라교육원 운동장 49개와 황혼 진단

- 사용자 지시에 따라 운동장 중앙의 지도 근사 좌표 33.42785°N, 126.53208°E를 사용했다. SQM-L 49개 원본, 좌표 도형과 근거·시간·선택 조건, 새 위치에서 받은 3시간 API 전체와 수신 기록을 보존했다. 이번 관측에서 확인되지 않은 차폐 정보로 방향을 제거하지 않았다.
- 001은 이전 후보를 이번 실측에 다시 맞추지 않은 고정 평가다. 기본 MSE/RMSE 2.97291661/1.72421478, 이전 후보 1.52032002/1.23301258이었다.
- 태양 고도 −9.14596°~−10.38456°로 항해 황혼임을 확인했다. 002는 앱 기본 모델에 두 계수의 경험적 태양 방향 휘도를 추가한 국소 연구다. 전체 보정 MSE/RMSE 0.21622258/0.46499739, 7개 방향 분할 검증 0.30499330/0.55226198이었다.
- 개별 시각·황혼 시간 변화·직접광·SQM-L 응답을 분리하지 못하며, 후보 형태도 이 자료를 본 뒤 정했다. 같은 구간의 검증을 독립적인 다른 날짜 검증으로 표현하지 않는다. 두 후보는 연구 전용이며 앱 기본값과 계산식은 유지했다.
- 입력/예측/지표/방위각·고도별 RMSE/비교 그래프/재현 조건·해시와 색인·설명을 저장했다. 황혼 분류·시간대·양의 빛 추가·천정 방위각 불변성·범위 밖 입력 검사 등을 포함해 관련 테스트 15개가 통과했다. 추가 외부 연구 참고 자료도 출처 목록에 기록했다.

## 2026-10-22~23 · 새 SQM-L 49개 및 3시간 API 보정

- 사용자는 장비를 SQM-L로 고정하고, 이전 관측을 보정·검증에서 빼고 새 49개를 사용하도록 지정했다. 이번에는 건물 차폐가 없으며 300°~345°도 모두 포함했다.
- 새 Meteoblue `airquality-3h`, `clouds-3h`, `air-3h`를 한 번씩 수신했다. 실제 시간 배열은 모두 3시간 간격이며 차감 헤더 합계는 24,000 크레딧이었다. 자격 증명을 제거한 전체 패키지 JSON과 수신 기록을 보존했다.
- 실행 001의 기존 계수만 맞춘 RMSE는 1.63006이었다. 실행 002에서 기존 산란 계수 범위 후보와 새로운 경험적 구름·달빛 항을 함께 비교했다.
- 새 후보의 전체 MSE 0.35074 / RMSE 0.59224, 방향 구간 검증 MSE 0.39276 / RMSE 0.62671이었다. 기본 모델은 MSE 3.68461 / RMSE 1.91953이다.
- 분할 내에서만 g·연속 계수를 보정하고, 전체 재계산·교차 고도/시각 진단·측정 시간 범위 민감도를 보존했다. 새 항의 계수는 물리적 검증값이 아니며 탐색 경계·장비 각도 응답·단일 밤의 한계를 명시했다. 앱 모델과 기본값은 변경하지 않았다.
- 기존 평가기가 실험 전용 계수를 조용히 무시하지 않도록 검증을 추가했다. 입력·시간대·자격 증명 제거와 기존 평가를 포함한 테스트 9개가 통과했다.
