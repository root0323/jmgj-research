# 모델 연구 변경 기록

## 2026-10-21 · 방향별 RMSE 평가 기능

- `evaluator.py`에 방위각·고도별 RMSE 그래프와 관측 수, 방향별 오차표, 전체 지표 및 예측 CSV 저장을 추가했다.
- 고정 API 파일을 읽는 연구용 시간대 어댑터를 연결해 네트워크 호출 없이 현재 모델을 평가할 수 있게 했다.
- `003_directional_rmse`에 건물 차폐 4개를 제외한 21개 관측의 기본 모델 및 기존 보정 후보 재계산을 보존했다. 원본과 이전 실행은 유지했다.
- 기본 MSE 0.58565 / RMSE 0.76528, 기존 후보 MSE 0.41471 / RMSE 0.64398이다. 이는 같은 자료에 대한 재평가이며 새로운 날짜의 독립 검증이 아니다. 모델 계수나 앱 기본값은 변경하지 않았다.

## 2026-10-15 · 제주 관측 첫 기록

- 관측 25개 및 사용자가 지정한 API JSON 전체 원본을 보존했다.
- `001_all_25`: 원본 전체를 대상으로 기본 모델과 인공광 계수 후보를 비교했다.
- `002_unobstructed_21`: 사용자 정정에 따라 건물에 가린 방위각 300°·315°·330°·345°의 네 관측을 제외하고 보정·평가를 다시 했다.
- 기존 API JSON의 UTC 시간축을 한국 관측 시각과 맞췄다. 모델 소스·계수·입력 어댑터·자료 해시를 함께 보존했다.
- 최신 계수 후보는 0.673216이다. 구간 검증에서 기본 모델보다 개선되지 않아 앱 기본값에는 적용하지 않았다.
- 앞으로 원본과 이전 실행을 보존하고 새 자료·수정 기준·모델 후보·검증 결과를 새 실행으로 추가한다.
