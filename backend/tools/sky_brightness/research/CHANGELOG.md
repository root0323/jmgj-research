## 2026-10-28 · 물리 전달 개정

- 최신 사용자 지시에 따라 연구 후보와 앱 기본값을 분리했다. 이번 준비본도 앱에 반영하지 않으며 공개 앱 0.9.3·legacy를 유지한다. 앞으로 원본·조건·지표·그래프는 계속 보존하고 앱 반영은 별도 명시 요청이 있을 때만 진행한다.

- 첫 연구의 설계 배경과 2024·2025년 문헌을 검토하고 기존 인공광·지형 입력에 방향별 복사전달을 연결했다. 저자 프로그램이나 논문 도표를 복사하지 않았다.
- 달 원반·실제 각거리의 첫 산란·SQM-L 응답, 광학 두께에 따른 구름 전달, 광원별 차수 수렴을 구현했다. 운량²·전체 다중산란 배수는 기존 앱·legacy 재현 경로에 남기고 연구 후보에서 교체한다.
- 22일·27일 유효 82개를 새 실행 003으로 사후 비교했다. 원본·API는 보존하며 27일의 악화도 포함해 MSE/RMSE·예측·방향 그래프·민감도·격자/실제 WASM 검증을 저장했다. 미래 날짜 검증으로 표현하지 않는다.
- API 기압 0의 보간을 막고, 연구에서 필요한 미확인 밑면·광학 두께는 가정으로 기록했다. 새 유료 API 호출은 없었다.
- 평가 도구는 SQM-L 응답과 새 모델을 선택하고 원본·조건·해시·그래프를 새 출력 폴더에 보존한다. 연구 후보의 로컬 호환성만 검증했다. 앱 기본값과 빌드 설정은 기존 상태로 유지하며 0.9.4 준비본은 미게시 상태로 보관한다.
