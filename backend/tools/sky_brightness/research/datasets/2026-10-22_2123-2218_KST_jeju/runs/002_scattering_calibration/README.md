# 실행 002 · 산란 후보 비교

새 SQM-L 49개 전부, 새 3시간 API, 최대 광원 1,000개·반경 30km를 사용했다. 이전 관측은 보정·검증에 사용하지 않았다.

| 방법 | 전체 MSE | 전체 RMSE | 방향 구간 검증 MSE | 방향 구간 검증 RMSE |
| --- | ---: | ---: | ---: | ---: |
| 기본 모델 | 3.68460729 | 1.91953309 | 3.68460729 | 1.91953309 |
| 기존 산란 계수 범위 내 보정 | 1.37955741 | 1.17454562 | 1.55696763 | 1.24778509 |
| 경험적 구름·달빛 후보 | 0.35074235 | 0.59223505 | 0.39276223 | 0.62670745 |

최적 실험 후보: `g=0.5`, `art_scale=0.05`, `moon_cloud_gain=118.24386924943558`.
추가 항은 `I_moon * moon_cloud_gain * cloud_effect_fraction`이다. 물리적 원인이 검증된 증폭률이 아닌, 이 밤에 맞춘 경험적 항이다.
g와 인공광 계수는 하한에 걸렸다. SQM-L 각도 응답·달의 직접 유입, 실제 빠른 구름 변화와 분리하지 못했다.
**연구 후보이며 앱의 `calculator.py`와 기본 계수는 변경하지 않았다.**

![실측과 예측](observed_vs_model.png)

![방향 구간 검증 RMSE](angular_holdout/rmse_by_direction.png)

- 60° 방향 6개 구간을 두 고도에서 함께 제외하고, 천정은 별도 제외해 총 7개 분할을 만들었다. 각 분할의 g·연속 계수는 학습 자료만으로 보정했다. 모든 관측이 한 번씩 검증에 사용된다.
- 후보 계열 선택도 같은 진단 오차를 참고했으므로 별도 독립 검증이라고 주장하지 않는다. 다른 밤·위치 자료는 없다.
- 고도 30°→60° 예측 RMSE 0.70675, 60°→30°는 0.49189다. 측정 시각도 달라지는 진단이다.
- 구간 시작/종료 시각의 고정 후보 RMSE는 0.58996/0.59331이었다. 최대 예측 변화는 0.02783 mag/arcsec²다.
- `scattering_components.csv`에는 g=0.5~0.9 각각의 원래 물리 성분이 있다. `comparison.csv`는 비교한 모든 후보·검증 예측을 포함한다.
- `candidate_params.json`은 실험 항을 포함하므로 `calibrate_scattering.py`의 연구용이다. 기존 `evaluator.py --params`로는 이 항을 계산할 수 없다.
