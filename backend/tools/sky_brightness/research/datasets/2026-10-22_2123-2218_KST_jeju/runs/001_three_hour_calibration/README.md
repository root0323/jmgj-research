# 실행 001 · 기존 계수만 보정

새 SQM-L 49개 전부와 새 3시간 API를 사용했다. 이전 관측은 포함하지 않았다.
`calibrate_three_hour.py`가 현재 `calculator.py`의 인공광 계수와 달 투과 계수만 기존 범위에서 맞췄다.

| 방법 | 전체 MSE | 전체 RMSE | 방향 구간 검증 RMSE |
| --- | ---: | ---: | ---: |
| 기본 모델 | 3.68460729 | 1.91953309 | 1.91953309 |
| 인공광만 | 2.70094258 | 1.64345446 | 1.64345446 |
| 인공광·달 투과 | 2.65711168 | 1.63006493 | 1.63006493 |

후보는 `art_scale=1.5`, `moon_transmission_scale=0.5`로 모두 탐색 경계였다.
방향 검증의 모든 학습 분할에서도 같은 경계를 선택해 전체 보정/방향 검증 오차가 같아졌다. 이를 독립 검증 성공으로 해석하지 않는다.
계수 보정만으로 부족해 [실행 002](../002_scattering_calibration/)에서 산란 후보를 비교했다.

[전체 자료·시각·단위·API·장비·재현 안내](../../README.md). `report.json`에 전체 계열·검증 분할·교차 고도 진단·시간 구간 민감도, `run.json`에 입력·소스·자료 해시가 있다.
