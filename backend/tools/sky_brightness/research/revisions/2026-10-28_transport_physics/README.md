광학 두께 10·층 두께 1km는 API 관측값이 아닌 명시적인 가정이다. 1·10·30은 신뢰구간이나 오차가 최소인 값을 고른 결과가 아니다. 10월 27일 기압 0→922hPa 보간은 무효로 보고 2km 밑면을 가정했다. 22일의 대류운 밑면 기압도 일반적인 모든 구름의 밑면을 측정한 값과 같지 않다.

새 모델에는 전체 밝기에 곱하는 다중산란 계수가 없다. 차수별로 방향·위치·성분을 전달하며 수렴 실패를 결과로 받아들이지 않는다. 두꺼운 구름 시험의 최초 160차는 부족했으므로 최대 512차까지 허용하되 실제 정지 차수와 잔여 추정을 기록했다.

반경 30km·같은 위성광/DEM·99% 누적 광량/최대 1,000픽셀 조건이다. 22일 49개, 27일 유효 33개·결측 16개를 유지했다. 15일은 보관 전용, 26일은 황혼 자료여서 이 야간 비교에 넣지 않았다. 원본과 API는 각 데이터 세트의 기존 파일을 SHA-256으로 참조한다. 새 유료 API 조회는 하지 않았다.

이전 기본값 열은 당시 앱의 점방향 예측이다. 물리식만 같은 응답에서 비교하려면 새 하늘 열을 사용하며, 새 SQM-L 열에는 측정기 응답을 추가한 효과도 들어 있다. 가까운 현장 조명의 점등 시각·상세 차폐와 실제 달 가림 정보가 없어 잔차 원인을 확정하지 않는다.
